# jimena.ca — My Portfolio Website

My personal portfolio website. I designed and built it with React.

**Live site:** https://jimena.ca

## About

This website shows my work as a front-end developer and UI designer. I built it with small, reusable components, so the code is clean and easy to update.

## Built With

- React
- React Router
- Sass
- Firebase Hosting

## Project Structure

- `src/components` — reusable components (header, portfolio item)
- `src/pages` — the pages of the site (Home, Portfolio, Contact)
- `src/assets` — images and other files

## Run the Project Locally

npm install
npm start

Then open http://localhost:3000 in your browser.

## Deployment

The site is hosted on Firebase. When code is merged to the `main` branch, GitHub Actions deploys the new version automatically.

## What I Focused On

- Clean and simple code that is easy to read
- Small components with one job each
- A design that works on phones and computers
